# Episode

The home for one podcast or video episode. The media feed lister returns a channel's or a feed's episodes; each one is filed here as its own artifact, holding that episode's data exactly as the lister produced it, under the episode's own title. An episode becomes something you can open, read, link to and review on its own, instead of a row inside one long list.

Install from the Cinatra marketplace by searching for "Episode" and clicking **Add**. No credentials or configuration are required; the type is active immediately for all workspace members. Opening an episode shows what the feed carried: its title, when it was published, how long it runs, what it is about, and the addresses of the media itself and of the episode's own page. A field the feed did not carry is not shown at all — the view never invents one and never leaves an empty line where one would have been.

## Works with

- The media feed lister, which files one episode per entry it returns
- The artifact library — open any episode to see it on its own page
- A review — the same view draws on the review card
- A third-party application — the view draws there too, because it reads only what the host hands it and never fetches

## Capabilities

- A dedicated episode type, so an episode resolves its own display everywhere it appears
- One episode per artifact, its data unchanged from the agent that produced it
- A full view and a compact view over the same reading
- Never a blank view: content it cannot draw is named in a sentence, and incomplete data is refused rather than drawn wrongly
- Read-only by construction — it carries no decision control of its own
